Тема проекта: «Моя библиотека» (список книг)

Задания идут по порядку, каждое продолжает предыдущее.
Работайте в отдельной папке: index.html, main.js, styles.css.
Вкладка Network в DevTools всё время открыта: проверяйте там каждый запрос.


============================================================
ЗАДАНИЕ 0. Подготовка (5 мин)
============================================================

1. Зайдите на mockapi.io и создайте новый проект.
2. Создайте ресурс books с полями:
   - title     (string)  название
   - author    (string)  автор
   - year      (number)  год издания
   - isRead    (boolean) прочитана или нет
3. Сгенерируйте 20 записей.
4. Откройте в браузере адрес https://ВАШ_ID.mockapi.io/books
   и убедитесь, что видите JSON с книгами.

Проверь себя: в браузере открывается массив из 20 объектов.


============================================================
ЗАДАНИЕ 1. GET: вывести книги (5 мин)
============================================================

1. В main.js создайте константу API с адресом ресурса books.
2. Напишите async-функцию getBooks, которая получает книги через fetch.
3. Выведите каждую книгу на страницу карточкой:
   название, автор, год и отметка «прочитана» или «не прочитана».

Проверь себя: на странице 20 карточек, в Network один GET со статусом 200.


============================================================
ЗАДАНИЕ 2. POST: добавить книгу через форму (10 мин)
============================================================

1. Сделайте форму с полями title, author, year и чекбоксом isRead.
   У каждого поля должен быть атрибут name.
2. При отправке формы соберите данные через new FormData(form).
3. MockAPI ждёт JSON, поэтому превратите FormData в обычный объект:
      const data = Object.fromEntries(new FormData(form));
   Выведите data в консоль и посмотрите, что получилось.
4. Отправьте data методом POST в формате JSON.
5. Новая книга сразу появляется в списке, форма очищается.

Вопросы (ответьте в комментарии в коде):
   - Какого типа получился year: число или строка? Почему?
   - Что лежит в isRead, если чекбокс не отмечен?
   Исправьте оба поля перед отправкой, чтобы year был числом,
   а isRead был true или false.

Проверь себя: в Network POST со статусом 201, у новой книги есть id.


============================================================
ЗАДАНИЕ 4. Query-параметры (15 мин)
============================================================

Над списком добавьте панель с фильтрами. При любом изменении
список загружается заново.

1. Фильтр: select «Все / Прочитанные / Непрочитанные»
      ?isRead=true
2. Поиск: input по названию
      ?search=...
3. Сортировка: select «По году» или «По названию», плюс порядок
      ?sortBy=year&order=desc
4. Пагинация: показывать по 5 книг и кнопка «Загрузить ещё»
      ?page=1&limit=5
   - При нажатии загружается следующая страница и добавляется
     в конец списка, старые карточки остаются.
   - Когда книги закончились, кнопка пропадает.
     Как это понять? Подумайте, сколько книг придёт на последней странице.

Собирайте query через URLSearchParams, а не склеиванием строк.
Попробуйте найти книгу по-русски и посмотрите в Network, как выглядит адрес.

Подводный камень: если ничего не нашлось, MockAPI отвечает 404, а не [].
Покажите в этом случае надпись «Ничего не найдено».

Проверь себя: выберите «Прочитанные» и сортировку по году.
В Network должен уйти один запрос со всеми параметрами сразу.


============================================================
ЗАДАНИЕ 5. PUT и DELETE (10 мин)
============================================================

1. В каждую карточку добавьте кнопку «Удалить».
   Метод DELETE, адрес /books/:id.
   Карточка исчезает только после успешного ответа сервера.
2. Кнопка «Прочитана / Не прочитана» меняет isRead методом PUT.
3. Проверка ошибок: временно отправьте DELETE на /books/99999.
   - Что пришло в Network?
   - Сработал ли catch?
   - Почему?
   Добавьте проверку response.ok и выбрасывайте ошибку,
   если сервер ответил не 2xx.

Проверь себя: после перезагрузки страницы удалённые книги
не возвращаются, а отметка «прочитана» сохранилась.


============================================================
ЗАДАНИЕ 6. Рефакторинг: модуль api.js (10 мин)
============================================================

1. Создайте файл api.js.
2. Перенесите туда функцию request(url, method, body), которая:
   - делает fetch с нужным методом и заголовком Content-Type,
   - превращает body в JSON, если он передан,
   - выбрасывает ошибку, если response.ok равен false,
   - возвращает response.json().
3. Экспортируйте однострочники:
   getBooks(query), createBook(book), updateBook(id, book), deleteBook(id)
4. В main.js импортируйте их. В index.html поставьте
   <script type="module" src="./main.js">.
5. В main.js не должно остаться ни одного fetch.
